変更されたファイルを確認し、CLAUDE.local.mdのコミットガイドラインに従って、適切な粒度で**自動的に**ステージングとコミットを実行してください。

## 実行手順

### 1. 変更の確認と分析
- `git status`と`git diff`を並列実行して、変更されたファイルを確認
- 変更内容を分析して、論理的なまとまりごとにグループ化

### 2. グループ化の基準
- **機能単位**: 同じ機能に関連する変更をまとめる
- **層単位**: データベース層、ビジネスロジック層、API層、UI層など
- **ファイル種別**: 実装ファイルとテストファイルは別グループ
- **依存関係**: スキーマ → ビジネスロジック → API → UI の順序を考慮
- **除外**: CLAUDE.md、CLAUDE.local.md、.env.exampleは基本的に除外

### 3. 自動ステージングとコミット
**ユーザーに確認せず**に、以下の手順で自動実行してください:

1. グループ1の変更をステージング
2. CLAUDE.local.mdの形式に従ってコミット実行:
   - 絵文字 + 半角スペース + 概要
   - 詳細は箇条書き
   - HEREDOCを使用
   - Claude Codeの署名を含める
3. グループ2以降も同様に繰り返す

### 4. 結果の報告
すべてのコミットが完了したら、コミット一覧を表形式で報告してください。

## 注意事項

- **確認不要**: ユーザーに確認を求めずに自動実行してください
- **細かく分割**: 1コミット1目的の原則に従って細かく分割
- **実装とテストは分離**: 実装ファイルとテストファイルは必ず別コミット
- **変更なし**: 変更がない場合は、その旨を伝えてください
- **エラー処理**: ステージングやコミットでエラーが発生した場合は、ユーザーに報告してください
