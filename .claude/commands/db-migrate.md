未適用のマイグレーションファイルを確認し、データベースに適用してください。

## 実行手順

### 1. 未適用のマイグレーションを確認

以下を並列実行して、マイグレーションの状態を確認してください:

- `ls apps/core/db/migrations/*.sql` で全マイグレーションファイルを一覧表示
- 最新のマイグレーションファイルを読み込んで内容を表示

### 2. ユーザーに確認

未適用のマイグレーションがある場合、以下の情報を表示してユーザーに確認を求めてください:

```
以下のマイグレーションを適用します:

ファイル: 20251130095725_create_user_names.sql
内容:
  CREATE TABLE "user_names_table" (
    ...
  );

このマイグレーションをデータベースに適用しますか？ (y/N):
```

### 3. マイグレーションの適用

**重要**: ユーザーが確認（`y`または`yes`）した後、以下を実行:

1. `cd apps/core`
2. `bun run db:migrate`
3. 実行結果を確認して表示
4. 成功した場合は、適用されたマイグレーションを報告

### 4. エラーハンドリング

- **未適用のマイグレーションがない場合**: 「すべてのマイグレーションは既に適用されています」と報告
- **マイグレーション失敗の場合**: エラー内容を表示し、ロールバック方法を案内
- **データベース接続エラー**: 環境変数（POSTGRES_URL）の確認を促す

## 安全対策

- 実行前に必ずマイグレーション内容を表示
- ユーザーの明示的な確認を必須とする
- エラー発生時は即座に停止

## 便利な情報

実行後、以下の情報を提供してください:

- 適用されたマイグレーション数
- データベースの現在の状態
- 次のステップの提案（例：テストの実行、コミット、など）
